# Astel

Human-supervised AI calling prototype.

## Local setup

1. Copy `.env.example` to `.env.local` and add your SignalWire credentials.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

The current milestone places an outbound SignalWire call and plays a short TTS test message. Never commit `.env.local`.
